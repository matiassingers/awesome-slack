# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

## Project fit

- Search previous suggestions before making a new one, as yours may be a duplicate.
- Suggested additions must be specifically about Slack. Slack should be a core part of the project, not one optional output among several interchangeable integrations.
- General-purpose products and services will not be accepted solely because they can send notifications to Slack.
- Please do not submit Slack App Directory apps. Only open-source Slack projects will be accepted.
- The linked source repository must clearly state a recognized open-source license. A LICENSE file containing the full license text is strongly preferred.
- This is a curated list, not a marketing channel. Thin wrappers whose main purpose is to drive usage of a commercial API or service will be declined.
- New categories and improvements to the existing categorization are welcome.

## Project quality

- Projects must be useful, functional, and currently maintained.
- We review recent commits, release history, issue handling, contributor activity, and adoption signals such as stars, forks, package downloads, or documented usage. No single metric guarantees acceptance.
- A burst of activity around the submission does not demonstrate sustained maintenance. Newly created or self-submitted projects with little history or independent usage will normally be declined and can be submitted again once established.
- Automated, bulk, or irrelevant activity and suspicious engagement do not count as evidence of quality.
- Inactive projects will normally be declined, even if they were previously popular. Stable low-churn projects and official SDKs may be accepted when they remain functional and current.

## Pull request format

- Make an individual pull request for each suggestion.
- Keep descriptions short and simple, but descriptive.
- Start the description with a capital and end with a full stop.
- Check your spelling and grammar.
- Make sure your text editor is set to remove trailing whitespace.

Thank you for your suggestions!
